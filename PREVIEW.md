## 🚀 HOW TO RUN

### Start Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
✅ Visit: http://localhost:8000/docs

### Start Frontend
```bash
cd frontend
npm install --legacy-peer-deps
npm run dev
```
✅ Visit: http://localhost:3000
